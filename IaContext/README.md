# IA-Context

Pasta de contexto operacional para assistentes de IA trabalharem no ClassLog.

Esta pasta deve ser sincronizada por Syncthing entre maquinas, mas deve ficar fora do Git. O repositorio ignora `IA-Context/` em `.gitignore`.

Antes de continuar qualquer alteracao no projeto, leia:

- `AGENTS.md`
- `README.md`
- `docs/contexto.md`
- `docs/arquitetura.md`
- `docs/tarefas.md`
- `docs/decisoes.md`

Uso sugerido ao abrir o projeto em outra maquina:

```text
Leia o IA-Context/AGENTS.md e os arquivos em IA-Context/docs antes de continuar.
```
